# PitWall AI screenshots

Add screenshots of the deployed Streamlit app to this folder.

Suggested filenames:
- `dashboard-overview.png` — session overview and KPI summary
- `strategy-simulator.png` — historical multi-stop strategy optimizer
- `pre-race-planner.png` — pre-race planner and compound assumptions
- `strategy-robustness.png` — robustness and sensitivity analysis
- `tyre-calibration.png` — tyre calibration diagnostics

Use PNG or JPEG images, crop out browser/account details where possible, and avoid committing secrets or personal information.

Once images are added, embed them in the root `README.md` with relative paths, for example:

```markdown
![PitWall AI dashboard overview](screenshots/dashboard-overview.png)
```
